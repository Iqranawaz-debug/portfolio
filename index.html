DeepTrace AI

A local-first agentic research workspace: it plans bounded research, saves each source, and writes reports where every finding cites a saved passage — verified by code, not a model.

  • Python
  • RAG
  • LLM Agents
  • Gemini
  • Tavily
  • SQLite
9 / 9Quotations matched in first live run
2Invalid citations caught & suppressed
Read the case studyProblem, implementation & outcome — DeepTrace AI+
Engineering notes01

Problem

AI research assistants are fast but hard to trust: they cite sources that don't contain the quoted words, mix opinion with evidence, and send data off your machine.

Approach

A bounded Plan → Discover → Read → Check → Report pipeline with hard limits on searches, pages, tokens and time. A finding is “Cited” only if deterministic checks confirm its passage and quotation.

Technical implementation

Python backend with SQLite storage, an evidence inspector UI, robots.txt-aware fetching, SSRF protection, mock mode by default, and versioned SHA-256-checked Markdown reports.

Result

Run end to end against real Tavily and Gemini free tiers: 7 cited findings, 9 of 9 quotations matched, 2 invalid citations caught. Backend test coverage last measured at 92%.

Read the case studyProblem, implementation & outcome — ResumeIQ+
Engineering notes03

Problem

Most resume checkers return a single opaque number with no explanation of what matched or what to improve.

Approach

Mark each job requirement as Matched, Partial, Not evidenced or Can't assess, with a quote from the resume, and show the exact scoring formula and weights.

Technical implementation

FastAPI backend with PDF/DOCX parsing and rule-based extraction; React + Vite frontend; optional OpenAI-compatible AI validated and shown beside the local result.

Result

A full-stack app with “what would change this score” simulations, resume versioning, readability checks and a safe CSV/PDF comparison export.
