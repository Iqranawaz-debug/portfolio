01 Applied AI · RAG Closed · Milestone 1 complete Oct–Nov 2026

DeepTrace AI

A research assistant that has to show you the sentence before it’s allowed to make the claim.

The problemAI research tools cite pages that don’t contain the quoted words.

  • DecisionCitations are checked by deterministic code: the passage must exist, must have been allowed for this run, and must contain the quotation.
  • BuiltA local-first Python/FastAPI and SQLite backend, a React/TypeScript workspace, and a bounded Plan → Report pipeline over Tavily search and Gemini.

Honest limit: a valid citation proves the source says those words — not that the claim is true. Checking whether a passage supports a claim was planned for a later milestone and not built.

What I’d do differently

Get CI running on GitHub before building features, and plan for a busy free-tier model from day one — a fallback model, or a “retry the answer only” step that reuses the passages already read.

02 NLP · Full-stack AI Open source · not hosted Jul–Oct 2026

ResumeIQ

A resume checker that explains its number — and admits what it can’t know.

The problemResume checkers hand back one opaque score, with no way to see what matched or why.

  • DecisionLocal rules always compute the score. Optional AI is validated and shown beside it — never instead of it.
  • BuiltFastAPI with PDF/DOCX parsing and rule-based extraction; a React + Vite frontend; a recruiter workspace; optional SQLite; Docker Compose and CI.

Co-built with Arisha Salman, who started the project in July 2026. I led the October rebuild: explainable results, requirement review, grounded rewrites, privacy controls and the recruiter workspace.

What I’d do differently

Build and run the Docker images and CI in the same pass as writing them — the README still lists them as unverified — and ship a hosted demo so people can try it without cloning.

03 Predictive modelling Live demo 2026

Bank Marketing Intelligence

Who’s worth calling? A model that only uses what the bank knows before the phone rings.

The problemCalling every customer is expensive; rank them before the campaign call.

Try it liveScore a customer or upload a CSV in the Streamlit app ↗ (opens in a new tab)
  • DecisionCall duration is dropped: it’s only known after the call, so using it would leak the answer into the model.
  • DecisionXGBoost chosen by 3-fold cross-validated average precision; the 0.375 threshold maximises out-of-fold F1 — exploratory, not cost-optimised.
What I’d do differently

Choose the decision threshold from campaign costs — the price of a call and the value of a subscription — instead of maximising F1, which the app itself labels exploratory.

Field note · Desktop automation · Oct 2026

Smart Screenshot Organizer

The problemA screenshots folder full of “Screenshot (42).png”, impossible to search.

A small tool for a universal mess. It reads each new screenshot with Tesseract OCR, names it from visible evidence, files it by category and keeps a searchable local history. OCR and explainable rules — no LLM, no cloud.

What I’d do differently

Give the command-line watcher the same missed-file reconciliation that background mode already has, instead of relying on create and rename events alone.

IN·03About

The short version.

I like the unglamorous middle of data work — where a messy dataset turns into something a person can actually use.

I studied Computer Science (Data Science) at NED University in Karachi and graduated in 2026. Along the way I ran IT Fundamentals labs for 60+ students, did IT operations at the Karachi Development Authority, and spent summer 2026 building AI automation for a fintech platform at Logiciel Services.

My projects keep circling one question: how do you make an AI system’s output checkable? Sometimes the answer is a citation validator. Sometimes it’s a visible formula. Sometimes it’s refusing to use a feature you won’t have at prediction time.

  • Check the evidence with code, not trust.

    In DeepTrace AI, a finding only counts as cited when deterministic checks find its quote in a saved source.

  • A pattern is an association, not proof.

    In Bank Marketing Intelligence, insights guide what to test next — they never promise uplift.

  • Show the work behind every score.

    In ResumeIQ, every requirement comes with a quote, and the scoring formula is on screen.
